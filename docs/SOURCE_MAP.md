核验对象：用户上传的 `dive-into-design-patterns-en-demo.pdf`，45 个物理页面，封面版本 `v2021-2.28 DEMO VERSION`。
SHA-256：`2e20ad97c937230cb5e4c4dd505bb2f84066917861f1fbb75c57e55e1d0e1708`。

页码规则：**PDF 页**从文件第一页开始数；**书内页**取正文页脚。两者不能直接相加换算，试读版跳过了大量页面。
本项目逐页提取核对文字并查看了目录渲染页，未把原书缺失页当成已读取内容。

## 三种来源标记

- `BODY`：4 章，对应实际可读正文。中文笔记是独立归纳，练习、Java 实现和 JUnit 测试是原创。
- `OVERVIEW_ONLY`：4 章，PDF 只提供创建型概览中的简短描述；章节讲解和全部练习为扩展原创。
- `TOC_ONLY`：28 章，只能根据目录确认名称和起始页；章节讲解和全部练习为扩展原创。

各章证据和目录页码见 [章节索引](CHAPTERS.md)，可机读元数据见根目录 `chapter-manifest.json`。

## 目录覆盖规则

36 个可练习章节 = OOP 3 + 模式导论 2 + 良好设计 1 + 通用原则 3 + SOLID 5 + 创建型 5 + 结构型 7 + 行为型 10。
通用 GoF 清单常说 23 个模式，本 PDF 明确列出 22 个，未列 Interpreter；本项目按 PDF 不另添加第 23 个。
目录中的总标题是导航分组；How to Read This Book 归入学习指南，Conclusion 只作扩展复盘提示（原文未提供），没有伪造这些部分的原文。
